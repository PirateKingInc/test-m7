# Backlog

Ideas deliberately **out of scope** for v1 (see SPEC §10). None of these
should add a second gameplay input.

* **Mute / volume toggle** — a settings affordance outside the play input
  (e.g. an HTML button beside the canvas, or respecting a saved preference).
* **Daily seed** — everyone gets the same gap sequence each day; share your
  score + seed.
* **Replay / ghost** — runs are reproducible from seed + flap ticks, so a
  replay is ~1 byte per flap. Show your best run as a translucent ghost.
* **Seed input** — `?seed=` works today; a UI for typing / sharing it.
* **More biomes** — a harbour at dusk, a snowbound pass, a lantern festival.
* **More obstacle skins** — windmill sails, a dragon-hunter's net, siege
  ladders (still the same two rectangles underneath).
* **Weather** — cosmetic rain / snow particles per biome.
* **Achievements / medals** — bronze 10, silver 25, gold 40 (the cap).
* **Colour-blind & reduced-motion modes** — disable screen shake and flashes.
* **Haptics** — a `navigator.vibrate` tick on score / hit on Android.
* **Offline / PWA** — manifest + service worker so it installs to a home
  screen.
* **Localisation** of the few UI strings.
